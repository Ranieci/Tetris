# Tetris
A complete Tetris clone featuring clean OOP architecture with separated game logic and rendering. 
  ★ Designed an extensible tetromino system using inheritance and polymorphism.  
  ★ Implemented core gameplay systems including rotation, collision detection, line clearing, and score scaling.  
  ★ Developed advanced mechanics such as hold piece, ghost piece, next-piece preview, and hard drop.  
  ★ Built an asynchronous game loop and decoupled UI architecture using XAML/WPF.
